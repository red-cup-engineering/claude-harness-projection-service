Projects a machine-specific Claude actor's office-roster policy into one project-local .claude/agents/ runtime substrate, by calling the settlement's own installing-claude-as-an-agent instrument once per colleague office.

The policy projector checks root and colleague seating through the original
Principal Office Seating service. An explicitly empty colleague roster is
valid. Roster checks also compare generated agent bytes and the shared
instruction sources. The portable installer accepts the policy's skill pools
and supports a read-only `--check` operation.

The module entry point exports the recovered roster, permission and lifecycle
hook APIs. Hook projection reads executable coordinates from the supplied
catalog. It handles the declared owner's previous and retired coordinates
while preserving other handlers.

The recovered source came from the Claude section's
`lib/legacy/restored-from-main/2026-09-12-14b91c6/services/claude-harness-projection-service/`.
The current portable installer and original enterprise-URN policy inputs
remain supported alongside constituted actor addresses. Run `npm ci` and
`npm run verify` against the recorded package lock.
